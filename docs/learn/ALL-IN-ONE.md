# Parikshaa Learn: students ke liye "sab ek jagah" (research + plan, 19 Oct 2026)

**Owner ne kya maanga:** aur research karke batao kya jodein ki Parikshaa students ke liye **ek hi jagah sab kuch**
wala sabse accha platform bane: saari tech aur programming seekhna, projects banana, sab kuch. Har page aur flow ka
sabse accha UI/UX. Owner se kya chahiye, launch ka kharch, aur $200 plan par Opus 5.5 ultracode se build aur test me
kitne tokens aur mahine.

Saath ki docs: UX ka poora niyam [UX-BLUEPRINT.md](UX-BLUEPRINT.md) · [../LEARN-V2.md](../LEARN-V2.md) ·
[CODE-STUDIO.md](CODE-STUDIO.md) · [CONTENT-CATALOG.md](CONTENT-CATALOG.md) · [OPEN-PLANNING.md](OPEN-PLANNING.md).

## 0. Saar

1. **Sab ek jagah = 7 stambh:** Seekho · Practice · Banao · Saboot (certify) · Muqabla · Career · Saath (community).
   Inme se ~60% plan ho chuka; is doc me **25 nayi cheezein** hain jo Parikshaa ko alag banati hain (§3).
2. **Sabse bada daav: phone-first coding.** Bharat me 97% gharon me phone hai, sirf 7% me laptop/computer. Duniya ke
   platforms laptop maan kar bane hain. Hum phone par seekhne ke tareeke banayenge (code ke tukde jodna, output
   predict, bug pakadna, dry-run "agla kadam") aur laptop/college lab par pura IDE.
3. **AI sahi tareeke se:** PNAS 2025 ki study ke mutabik bina guardrail wala AI tutor practice me madad karta hai, par
   exam me nateeja 17% gira deta hai; guardrail wala tutor ye nuksaan lagbhag rok deta hai. Isliye do mode: **Seekhne
   ka mode** (AI jawab nahi deta, sochne me madad) aur **Banane ka mode** (AI pair programmer, par khula hisaab).
4. **Kharch (launch tak, ek baar):** lean launch **~₹5 lakh** (review aap/TAs karein, pen test nahi), beech ka raasta
   **~₹15–20 lakh**, poora (paid reviewers, video DRM, live labs, app) **~₹33 lakh** (§7).
5. **Build ka samay:** ~140 sessions. $200 plan par ek account se **~5 mahine** (ultracode sirf design/review par), har
   slice ultracode se ~8 mahine; do accounts se ~2.5–4 mahine (§8).

## 8. Build: tokens, samay, $200 plan (Opus 5.5, ultracode)

**Kaam ki ginti** ([../LEARN-HANDOFF.md](../LEARN-HANDOFF.md) §4 + is doc ke N1–N25):

| Hissa | Sessions |
|---|---|
| Learn v2 build slices (F, S0, E, B, M, A, R, V, K, W) | ~81 |
| Is doc ki nayi cheezein (N1–N25) | ~20 |
| Content chalana (factory batches, fail theek karna; X, C) | ~30 |
| QA rounds (e2e, load, security, bugs) | ~10 |
| **Kul** | **~140** |

**Hamara naap (is project se):** ek bhaari ultracode slice ≈ ek 5-ghante ki window; ek din ki bhaari ultracode (6
agents + 3 critics) se ek account ki **hafte** ki limit 98% tak gayi; is lambe session ka API-daam par andaaza ~$980
(~6.2M output tokens, zyaadatar kharch purana context baar-baar padhne ka). Anthropic subscription ki limits tokens me
publish nahi karta, isliye neeche andaaza hai.

| Tareeka | Slices/hafta (ek account) | ~140 sessions | Subscription |
|---|---|---|---|
| Har slice ultracode | 3–5 | **~7–9 mahine** | ~$1,600 |
| **Mix (sujhav):** ultracode sirf design/review wale ~30% par, baaki normal, har slice naya session | 6–8 | **~4–5 mahine** | ~$1,000 |
| Mix, **do accounts** (ek Learn, ek content/QA) | 12–16 | **~2.5–3 mahine** | ~$1,200 |

**Tokens (andaaza):** ek normal slice ~150–250k output tokens (code + tests + docs), ultracode 2–3 guna. Kul ~25–35M
output tokens (mix) se ~60–80M (sab ultracode). API daam par ye ~$5,000–20,000 hota; subscription par ~$1,000–1,600.

**Test bhi isi me:** har slice me `npm run check` (typecheck + saare tests), web/console par build + budget, visual
baselines, e2e; R-slices me load (20k DAU), security, restore.

**Bachat ke niyam:** har slice naya session (handoff se), lamba context na khinchein, ultracode sirf zaroorat par,
content factory API (Batch) par alag.
