Recursion = function jo khud ko chhote input par bulaata hai. Do cheezein hamesha: 1. Base case: kab rukna (n == 0 → 1) 2. Chhota kadam: fact(n) = n × fact(n − 1)
int fact(int n) {
  if (n == 0) return 1;
  return n * fact(n - 1);
}
