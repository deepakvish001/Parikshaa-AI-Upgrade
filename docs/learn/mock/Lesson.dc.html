Two pointers: sorted array me jod

1. Sawaal samjho

Ek sorted array diya hai aur ek number K. Do alag index dhoondhne hain jinka jod K ho. Pehle khud se poochho: input kya hai, output kya hai, aur "sorted" shabd yahan kyun likha hai?

2. Brute force aur uski dikkat

Har jodi try karo: do loops, O(n²). n = 10⁵ par ye 10¹⁰ kaam hai, time limit me nahi chalega. Humne "sorted" ka faayda nahi uthaya.

3. Idea: do ungliyan

Ek ungli shuru par (L), ek aakhir par (R). Jod bada ho to R ko baayein lao, jod chhota ho to L ko daayein. Har kadam me ek number hamesha ke liye bahar ho jaata hai, isliye kul n kadam.
