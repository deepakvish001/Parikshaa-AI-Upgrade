Har sheher ka top seller

Har city ke liye wo seller batao jiski kul bikri sabse zyada hai. Barabari ho to dono dikhao. Kram: city, phir seller_name.

Tables
sellers(id, seller_name, city)
orders(id, seller_id, amount, created_at)

Submit par 4 chhupe datasets: barabari, NULL amount, bina order wala seller, khaali table.

PostgreSQL 16 Submit 
WITH totals AS (
  SELECT s.city, s.seller_name,
         SUM(o.amount) AS total,
         RANK() OVER (PARTITION BY s.city
                      ORDER BY SUM(o.amount) DESC) AS rk
  FROM sellers s JOIN orders o ON o.seller_id = s.id
  GROUP BY s.city, s.seller_name
)
SELECT city, seller_name, total FROM totals
WHERE rk = 1 ORDER BY city, seller_name;
