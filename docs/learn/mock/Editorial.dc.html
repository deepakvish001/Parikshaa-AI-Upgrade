Kadam 1: sawaal samjho

Code se pehle, sawaal ko apne shabdon me bolo: "Sorted list hai. Do alag jagah ke number chahiye jinka jod K ho." Ab teen cheezein likho:

  • Input / output: n, K, array; jawab do index ya -1 -1.
  • Chhupi shart: array sorted hai. Ye shabd bekaar nahi diya gaya.
  • Seema se lakshya: n = 2·10⁵, to O(n²) = 4·10¹⁰, nahi chalega.

Kadam 2: raasta dhoondho

Brute force: har (i, j) try karo. Sahi hai, par O(n²). Ab poochho: sorted hone se kya milta hai?

Observation: sabse chhota (a[0]) aur sabse bada (a[n−1]) jodo. Agar jod K se bada hai, to a[n−1] kisi ke saath bhi kaam nahi aayega, kyunki uska sabse chhota saathi bhi zyada de raha hai. Use hamesha ke liye hata do. Agar jod chhota hai, to a[0] ko hata do. Har kadam ek number kam, kul n kadam.

Kyun sahi hai: jo number hataya, uska koi saathi bacha hi nahi tha. Isliye sahi jodi kabhi nahi chhoot-ti. Ye "hamesha sach" wali baat (invariant) interview me bolo, yahi farq dikhata hai.

Socho: agar array sorted na hota? Hash map se O(n). Agar teen numbers chahiye? Ek number fix karo, baaki do par yahi trick: O(n²). Ye agla problem hai.
