Pair with sum K

Aapko n numbers ka ek array a diya hai jo badhte kram (non-decreasing) me hai, aur ek number K. Do index i < j dhoondho jinke liye a[i] + a[j] = K.

Agar kai jodiyan hon to koi bhi ek do; checker har sahi jodi maanta hai. Agar koi jodi na ho to -1 -1 print karo.

Input

Pehli line: n aur K. Doosri line: n numbers a[0] … a[n−1].

Output

Do numbers i aur j (0 se ginti), ya -1 -1.

Seema (constraints)

  • 2 ≤ n ≤ 2·10⁵
  • 0 ≤ a[i] ≤ 10⁹, a sorted
  • 0 ≤ K ≤ 2·10⁹
  • Time: 1 s (C++), 2 s (Java/Python)

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int n; long long k;
    cin >> n >> k;
    vector<int> a(n);
    for (auto& x : a) cin >> x;
    int l = 0, r = n - 1;
    while (l < r) {
        int s = a[l] + a[r];
        if (s == k) { cout << l << ' ' << r; return 0; }
        if (s > k) r--; else l++;
    }
    cout << "-1 -1";
}
