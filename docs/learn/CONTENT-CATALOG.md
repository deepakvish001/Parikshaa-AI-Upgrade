## 3. Design (har content type ka dhaancha)

### 3a. Course page

1. **Hero:** naam, level chip, ghante, "aap kya banayenge" (3 bullets + project screenshot), shuru/jaari rakho, progress ring.
2. **Kiske liye / pehle kya aana chahiye** (roadmap me jagah, prerequisites ke link).
3. **Syllabus:** modules ka accordion; har item ka icon (📖 lesson, 🧪 lab, ☑ problem, ❓ quiz), samay, ✓ status.
4. **Project(s)** jo banenge, aur Pramaan/certificate.
5. **Instructor/team** (owner ki kitaab wale course par owner ka naam), "AI ki madad, insaan ki jaanch" note.
6. FAQ; free vs Plus kya hai.

### 3b. Lesson (owner ki kitaab ki soch par)

1. **Kyun** (2–3 line, asli zindagi/interview ki baat).
2. **Concept** sketch visual ke saath ([VISUAL-STYLE.md](VISUAL-STYLE.md)), chhote paragraph, `Note` callouts.
3. **Udaharan** jo Studio me **chalta hai** (Run button).
4. **Galat-fehmi** (jo aksar galat samjha jaata).
5. **"Khud karo"**: 1 chhota kaam check ke saath.
6. **Quiz** (3–5), **revision card**, **aage kya**.
7. Hinglish toggle, padhne ka samay, "Sahayak se poocho".

### 3c. Guided lab

[CODE-STUDIO.md](CODE-STUDIO.md) §5: lakshya → padhna → likho → run → test → submit → samjhao → agla; aakhir me project
portfolio me.

### 3d. Arena problem

DSA jaisa ([USER-FLOWS.md](USER-FLOWS.md) F6) + domain ka Studio (preview/notebook/canvas). Editorial owner ki kitaab ki
4-kadam soch par, domain ke hisaab se (frontend: requirements samjho → component tree/state plan → likho → test/a11y
check).

### 3e. Article

1. Title (search intent ke hisaab se) aur 1 line ka vaada.
2. **TL;DR** (3 bullets).
3. Sketch hero visual (apna, code se).
4. Sections (H2/H3), code jo chal sake, tables.
5. **FAQ** (schema ke saath), "isse jude lessons/problems" CTA.
6. Lekhak + reviewer, "aakhri baar jaancha" taareekh, sources.
7. Hindi version (top articles ka).

### 3f. Cheat sheet

1–2 page, ek topic (jaise "Big-O ka saar", "SQL joins", "Git commands", "React hooks", "System design numbers"),
printable PDF (learner ka halka watermark), Plus me sab, free me 10.

**SEO ke niyam:**
- **Programmatic pages:** 5,000 problem pages (statement + approach ki jhalak, prerender), topic hubs, roadmap pages,
  company-pattern pages.
- schema.org (Course, Article, FAQPage, BreadcrumbList), sitemaps, canonical, internal links, Core Web Vitals.
- **Bahut saare AI articles chhapna Google ki "scaled content abuse" niti ke khilaaf ja sakta hai.** Isliye har
  article insaan edit karta hai, visuals apne, aur hamare apne data (anonymised) se kuch naya.
- Kram: launch par 3/hafta → 4th mahine se 10/hafta. Placement guides har season dobara jaanche jaate hain.
- Baantna: WhatsApp channel, LinkedIn, college groups, email newsletter; baad me YouTube Shorts.

## 5. Content kaise banega (pipeline, type ke hisaab se)

| Type | Draft | Machine jaanch | Insaan |
|---|---|---|---|
| Lesson | Factory (Opus Batch) + style guide | Code snippets runner par, quiz do model se, visual lint | 15 min review (100% pehle 3 mahine) |
| Guided lab | Factory draft + author mode | **Starter fail, solution pass**, mutation ≥ 90%, env boot test | **100% insaan ne poora lab khud karke dekha** (~2 ghante) |
| Arena problem | Factory | [PROBLEM-STANDARD.md](PROBLEM-STANDARD.md) §5 ke gates (domain ke hisaab se) | 10% sample (A2Z jaisa core 100%) |
| Article | Insaan ka outline + AI draft | Facts ke sources, links, code | **100% edit** |
| Cheat sheet | Lessons se nikala | Code/commands chala kar | 100% |
| AI course | Learner ke maangne par | Do model se quiz | Popular ho to review → "Expert ne jaancha" |
